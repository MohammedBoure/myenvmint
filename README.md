# MyEnvMint - بيئة العمل المتكاملة لنظام Linux Mint (X11)
### GlazeWM-Style Tiling • Polybar Status Bar • Picom Compositor • Zsh & Starship

مشروع متكامل ومحفوظ بالكامل يحتوي على كافة الإعدادات والسكربتات لتهيئة بيئة سطح المكتب بنمط GlazeWM المتطور مع الحفاظ الكامل على تطبيقات نظام Linux Mint الأساسية (Nemo، قائمة البداية، شريط المهام).

## ⌨️ جدول اختصارات لوحة المفاتيح (Keybindings)

### 1. التنقل بين النوافذ (Directional Navigation)
| الاختصار | الوظيفة |
| :--- | :--- |
| `Alt + h` أو `Alt + Left` | الانتقال إلى النافذة على اليسار |
| `Alt + l` أو `Alt + Right` | الانتقال إلى النافذة على اليمين |
| `Alt + k` أو `Alt + Up` | الانتقال إلى النافذة في الأعلى |
| `Alt + j` أو `Alt + Down` | الانتقال إلى النافذة في الأسفل |

### 2. التحكم في النوافذ (Window Management)
| الاختصار | الوظيفة |
| :--- | :--- |
| `Alt + q` | إغلاق النافذة النشطة فقط (WM_DELETE_WINDOW بدون إنهاء التطبيق) |
| `Alt + f` | ملء الشاشة للنافذة النشطة (Toggle Fullscreen) |
| `Alt + m` | تصغير النافذة النشطة (Minimize) |
| `Alt + Shift + Space` | توسيط النافذة في منتصف الشاشة |
| `Alt + u` / `Alt + p` | تصغير / تكبير عرض النافذة بنسبة 2% |
| `Alt + i` / `Alt + o` | تصغير / تكبير ارتفاع النافذة بنسبة 2% |

### 3. مساحات العمل (Workspaces 1 to 10)
| الاختصار | الوظيفة |
| :--- | :--- |
| `Alt + 1..9, 0` أو `Alt + & .. à` | التبديل إلى مساحة العمل والتركيز التلقائي على نافذتها (دون الحاجة للنقر) |
| `Alt + Shift + 1..9, 0` أو `Alt + Shift + & .. à` | نقل النافذة النشطة إلى مساحة العمل المحددة والانتقال التلقائي معها فوراً |

### 4. تشغيل البرامج وتغيير اللغة
| الاختصار | الوظيفة |
| :--- | :--- |
| `Win (Super)` (ضغطة مفردة) | فتح قائمة البرامج (Start Menu / Whisker Menu) |
| `Win + Space` | تبديل لغة الكتابة فوراً (فرنسية AZERTY / عربية) دون فتح القائمة |
| `Alt + Ctrl + Enter` | فتح الطرفية الحديثة (Zsh + Starship) |
| `Alt + n` | فتح محرر النصوص الافتراضي (xed) |
| `Alt + Ctrl + t` | فتح الطرفية في المسار المفتوح حالياً داخل مدير الملفات Nemo |

## 🛠️ كيفية التعديل والتخصيص (How to Modify)

جميع الإعدادات والسكربتات موجودة هنا مباشرة داخل المجلد:
1. لتعديل الاختصارات: عدّل الملف `config/sxhkd/sxhkdrc`.
2. لتعديل الشريط العلوي (الألوان، الوحدات، البيانات): عدّل `config/polybar/config.ini`.
3. لتعديل مظهر الطرفية: عدّل `config/starship/starship.toml` أو `config/zsh/zshrc`.
4. لتعديل أبعاد تقسيم النوافذ والمسافات بينها: عدّل `config/sxhkd/scripts/autotile.py` (متغيرات `GAP` و `OUTER_GAP`).

بعد إجراء أي تعديل، يكفي تشغيل السكربت التالي من داخل المجلد لتطبيق التغييرات فوراً:
```bash
./scripts/apply.sh
```

## 🚀 إعادة التثبيت أو النقل إلى جهاز جديد (Reinstall / Setup)

في حال قمت بإعادة تثبيت النظام أو أردت تشغيل هذه البيئة على جهاز جديد:
1. انسخ مجلد `myenvmint` إلى سطح المكتب `~/Desktop/myenvmint`.
2. افتح الطرفية داخل المجلد ونفّذ:
```bash
chmod +x scripts/*.sh
./scripts/install.sh
```
سيقوم السكربت تلقائياً بتثبيت الحزم المطلوبة، إعداد الشل، ربط ملفات الإعدادات، وإطلاق بيئة العمل بالكامل بضغطة زر واحدة.
