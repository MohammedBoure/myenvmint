# Zellij Configuration (`config/zellij/`)

This directory houses the user configuration for the Zellij Terminal Multiplexer.

## Files & Purposes

- **`config.kdl`**:
  The primary configuration file for Zellij in KDL format. It specifies keybindings (Normal, Locked, Pane, Tab, Resize, Scroll, and Session modes), theme definitions, UI layout defaults, copy/paste behaviors, and default shell options.
