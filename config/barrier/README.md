# Barrier KVM Configuration (`config/barrier/`)

This directory contains configuration files for Barrier, the open-source KVM software for sharing a mouse and keyboard across multiple computers over the local network.

## Files & Purposes

- **`Barrier.conf`**:
  The client configuration file for Barrier. Specifies the target server address (`192.168.84.219:24800`), screen names, and network parameters. Deployed to `~/.config/Debauchee/Barrier.conf`.
