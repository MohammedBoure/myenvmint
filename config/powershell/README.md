# PowerShell Configuration (`config/powershell/`)

This directory contains cross-platform PowerShell configuration profiles.

## Files & Purposes

- **`Microsoft.PowerShell_profile.ps1`**:
  Default user profile for PowerShell. Configures PSReadLine to display interactive vertical list predictions (`ListView`) sourced from historical commands with arrow and tab navigation. Also configures `explorer` and `open` helper aliases to open paths in the desktop file manager.
