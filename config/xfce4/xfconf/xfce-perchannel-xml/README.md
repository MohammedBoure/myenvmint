# Xfconf XML Channels (`config/xfce4/xfconf/xfce-perchannel-xml/`)

This directory contains individual XML configuration channel files for XFCE components.

## Files & Purposes

- **`xfce4-terminal.xml`**: Terminal geometry, custom dark palette, font size, transparent background, and cursor shape.
- **`displays.xml`**: Dual-screen monitor arrangement (`LVDS-1` and `VGA-1-1`).
- **`xsettings.xml`**: Active GTK theme (`Mint-L-Dark-Aqua`), icon theme (`ePapirus`), and font rendering.
- **`xfce4-keyboard-shortcuts.xml`**: Active XFCE keyboard shortcuts.
- **`keyboard-layout.xml`**: Input layout preferences and toggle options.
- **`xfwm4.xml`**: Window manager styling and window behavior properties.
- **Other XML channels**: Workspace names, desktop background properties, session management, and notification settings.
