# Xfconf Configuration (`config/xfce4/xfconf/`)

This directory houses exported configuration channels managed by the XFCE configuration daemon (`xfconfd`).

## Subdirectories & Purposes

- **`xfce-perchannel-xml/`**:
  Contains the full set of XML configuration channel files defining terminal styling, keybindings, display configurations, themes, and window manager settings.
