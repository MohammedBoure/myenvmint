# XFCE Panel Launchers (`config/xfce4/panel/`)

This directory contains panel launcher definitions and application shortcuts for the XFCE desktop panel.

## Subdirectories & Purposes

- **`launcher-3/`**, **`launcher-4/`**, **`launcher-5/`**:
  Contain desktop shortcut files (`.desktop`) configuring individual quick-launch icons on the panel.
