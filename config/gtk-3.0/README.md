# GTK 3.0 Configuration (`config/gtk-3.0/`)

This directory contains user-level GTK3 stylesheet overrides and theme enhancements.

## Files & Purposes

- **`gtk.css`**:
  Defines global GTK window decoration borders:
  - Enforces a crisp 2px active border (`#5294E2`) and 2px inactive border (`#5A6577`) on client-side decorated (CSD) applications and tiled windows.
  - Ensures seamless visual distinction between dark-themed programs across the entire desktop environment.
