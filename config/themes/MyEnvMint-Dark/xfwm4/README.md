# MyEnvMint-Dark xfwm4 (`config/themes/MyEnvMint-Dark/xfwm4/`)

This directory contains the window frame decorations, title bar assets, and button pixmaps for xfwm4.

## Files & Purposes

- **`left-active.xpm` / `left-inactive.xpm`**: 3px side borders (`#5294E2` active, `#5A6577` inactive).
- **`right-active.xpm` / `right-inactive.xpm`**: 3px side borders (`#5294E2` active, `#5A6577` inactive).
- **`bottom-active.xpm` / `bottom-inactive.xpm`**: 3px bottom borders (`#5294E2` active, `#5A6577` inactive).
- **`bottom-left-active.xpm` / `bottom-left-inactive.xpm`**: Corner joiners.
- **`bottom-right-active.xpm` / `bottom-right-inactive.xpm`**: Corner joiners.
- **`top-left-active.xpm` / `top-right-active.xpm`**: Upper corner joiners with 2px top and 3px side borders.
- **`title-1-active.xpm` to `title-5-active.xpm`**: Titlebar segments with 2px top border.
- **`close-*.xpm`, `hide-*.xpm`, `maximize-*.xpm`, `menu-*.xpm`, `shade-*.xpm`, `stick-*.xpm`**: Window title bar control buttons.
- **`themerc`**: Color configurations, button margins, and title offsets for xfwm4.
