# Themes Directory (`config/themes/`)

This directory houses customized desktop themes providing enhanced visual hierarchy and high-contrast window boundaries across the desktop environment.

## Directories & Purposes

- **`MyEnvMint-Dark/`**:
  Custom XFCE Window Manager (xfwm4) theme derived from Mint-L-Dark with dedicated, crisp 4-sided window borders:
  - **`xfwm4/`**: Contains window frame assets (`.xpm` pixmaps) and `themerc`:
    - **Active Window Borders**: Vibrant blue (`#5294E2`) 3px side/bottom borders and top-edge outline for immediate focus identification.
    - **Inactive Window Borders**: Distinct slate gray (`#5A6577`) 3px side/bottom borders and top-edge outline allowing clean visual separation between background applications and adjacent tiled windows.
    - Titlebar control buttons (close, minimize, maximize, stick, shade).
