# Micro Colorschemes Directory (`config/micro/colorschemes/`)

This directory contains custom and enhanced colorschemes for the Micro terminal text editor.

## Files & Purposes

- **`monokai.micro`**:
  Customized Monokai theme enhanced with syntax highlighting for all standard tokens, distinct error/warning gutter markers (`gutter-error`, `gutter-warning`), and dedicated styling for the interactive autocomplete popup tooltip (`identifier.autocomplete` and `identifier.autocomplete.selected`).
