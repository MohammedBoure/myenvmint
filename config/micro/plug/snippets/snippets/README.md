# Language Snippets Directory (`config/micro/plug/snippets/snippets/`)

This directory contains language-specific code snippet definitions for the Micro `snippets` plugin.

## Files & Purposes

- **`*.snippets`**:
  Snippet definition files covering major programming and configuration languages (including Python, C, C#, Go, Rust, JavaScript, HTML, CSS, Shell, and Zsh). Each file defines trigger keywords that expand into common boilerplate constructs upon pressing Tab.
