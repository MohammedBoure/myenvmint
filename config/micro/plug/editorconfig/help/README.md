# EditorConfig Plugin Help Directory (`config/micro/plug/editorconfig/help/`)

This directory contains help documentation for the Micro `editorconfig` plugin.

## Files & Purposes

- **`editorconfig.md`**:
  Documentation detailing how EditorConfig properties (`indent_style`, `indent_size`, `end_of_line`, `trim_trailing_whitespace`) map to Micro editor settings.
