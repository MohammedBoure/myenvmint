# Micro Editor Configuration (`config/micro/`)

This directory contains configuration files and plugins for the Micro terminal text editor.

## Files & Purposes

- **`bindings.json`**:
  Custom keybinding mappings for Micro:
  - `Ctrl-b`: Toggles the file manager tree sidebar (`tree` command).
  - `Ctrl-Backspace`: Deletes the previous word for faster terminal text editing.

- **`settings.json`**:
  Editor preferences, tab size, line numbering, auto-indentation, and color scheme settings.

- **`plug/`**:
  Contains editor plugins, specifically `filemanager` for project directory navigation.
