# Cinnamon Configuration (`config/cinnamon/`)

This directory houses Cinnamon desktop environment applet and spices configuration states.

## Subdirectories & Purposes

- **`spices/`**:
  Contains JSON settings files for active Cinnamon panel applets:
  - `menu@cinnamon.org`: Application menu search and layout options.
  - `calendar@cinnamon.org`, `sound@cinnamon.org`, `notifications@cinnamon.org`, `network@cinnamon.org`, `power@cinnamon.org`: Applet settings.
- **`menu@cinnamon.org/`**:
  Stores custom menu bookmarks and category configurations.
