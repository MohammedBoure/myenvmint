# Cinnamon Spices Configuration (`config/cinnamon/spices/`)

This directory contains configuration JSON files for active Cinnamon desktop applets and desklets.

## Subdirectories & Purposes

- **`calendar@cinnamon.org/`**: Calendar applet preferences and date format.
- **`notifications@cinnamon.org/`**: Desktop notification history and display rules.
- **`sound@cinnamon.org/`**: Audio volume controller and media player controls.
- **`network@cinnamon.org/`**: Network indicator and interface display options.
- **`power@cinnamon.org/`**: Battery and power management indicator settings.
- **`grouped-window-list@cinnamon.org/`**: Window taskbar grouping preferences.
- **`menu@cinnamon.org/`**: Application start menu layout and favorites.
- **`cornerbar@cinnamon.org/`**, **`favorites@cinnamon.org/`**, **`printers@cinnamon.org/`**: Applet state definitions.
